Every skill must take exactly these 3 parameters in this order:
state, log_fn, step_func

state is the current state of the game (an immutable EnvState, see below).
log_fn only takes a string and logs it in the trajectory log and prints a message. Use it to comment on actions inside a skill.
step_func takes an action id (e.g. Action.DO.value, see below) as the parameter, executes it and returns the new state (a skill may and often should execute several steps).

The state never changes in place. Every primitive and every skill returns the final state after its last step on success and raises an Exception on failure.
Therefore always reassign the state after calling step_func, a primitive or another skill, and return the final state at the end:

def mine_wood_and_make_pickaxe(state, log_fn, step_func):
    from craftax.craftax.constants import Action, BlockType
    if state.inventory.wood < 1:
        log_fn("Looking for a tree")
        state = explore_until(state, log_fn, step_func, BlockType.TREE)
        state = mine_block(state, log_fn, step_func, BlockType.TREE, 1)
    state = craft(state, log_fn, step_func, Action.MAKE_WOOD_PICKAXE)
    return state
